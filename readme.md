## 일정 기반 

`캘픽`은 너와 나의 시간을 `교집합`시켜, `함께`하는 순간을 더 쉽게 만들어요!

### 쉽게
약속이나 일정을 등록하면 달력에서 바로 확인할 수 있어요.
캘린더를 공유하면 로그인하지 않고 약속을 신청할 수 있어요

### 빠르게
현재 날짜와 시간을 자동으로 불러와 손쉽게 약속을 등록할 수 있어요.
물론, 원하는 날짜와 시간을 직접 선택할 수도 있어요

### 함께
친구에게 약속을 보내고, 상대방이 수락하면 서로의 캘린더에 자동으로 반영돼요.
각자 들어온 약속을 확인하고 관리할 수 있어요
